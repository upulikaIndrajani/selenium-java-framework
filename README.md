# Selenium Java Automation Framework

## Overview

This project demonstrates a scalable test automation framework built using Selenium WebDriver, Java, TestNG, Maven, and the Page Object Model (POM) design pattern.

The framework is designed to support functional testing, regression testing, smoke testing, and cross-browser testing.

## Technologies Used

* Selenium WebDriver
* Java
* TestNG
* Maven
* Page Object Model (POM)
* Git & GitHub

## Framework Structure

src
├── pages
├── tests
├── utilities
├── resources
└── reports

## Features

* Page Object Model (POM)
* Reusable test methods
* TestNG execution
* Detailed reporting
* Cross-browser support
* Easy maintenance and scalability

## Sample Test Scenarios

* Verify successful login
* Verify invalid login
* Verify logout functionality
* Verify password validation
* Verify navigation between pages
